02Return type

The person as a function signature: what you call is the name, what you get back is the role. The back returns the contact details.

FOUNDER · NULL
CODE: NON
// founder
alteisen()
:null
{ role: "founder" } // tap → save contact
FRONT
return {
  name: "Alteisen",
  mail: "null@codenon.io",
  web:  "codenon.pages.dev",
  ig:   "@codenon.io",
};
CODE: NON// scan, or tap the front
BACK
